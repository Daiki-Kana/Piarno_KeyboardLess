■ 1. プロジェクト概要
--------------------------------------------------------------------------------
本プロジェクト「Piarno_KeyboardLess」は、物理的なピアノ鍵盤やキーボードを必要とせず、
Webカメラに映した両手・指先の動きをMediaPipeでリアルタイムトラッキングし、
机面や空中でピアノ演奏を行える「鍵盤レス・エアピアノ（机面打鍵ピアノ）」アプリケーションです。

【技術スタック】
- 言語: TypeScript (Strict mode)
- ビルド/バンドラ: Vite 6
- 映像認識: MediaPipe Tasks-Vision (@mediapipe/tasks-vision 0.10.18, HandLandmarker)
- 音源エンジン: Web Audio API (オシレーター多重合成によるピアノ音・和音シミュレータ)
- 描画: HTML5 Canvas 2D (鏡像反転・Webカメラ映像オーバーレイ)
- デザイン方針: 白黒を基調としたミニマル・レスポンシブUI (余計な装飾を排した高視認性)


■ 2. 最新の開発進捗（完了した実装）
--------------------------------------------------------------------------------
本セッションでは、指ごとの相対的な位置関係を利用して正確に打鍵を検知する
「相互アンカー追従ライン（Line_Y）」の設計・実装から、実際に曲を演奏できる
テスト環境の構築までを完了しました。

【実装済み機能の詳細】

1. 手の基準スケール算出 (L_hand)
   - 手首（Landmark 0）から中指MCP（Landmark 9）のピクセル間距離を手の基準スケール「L_hand」として算出。
   - カメラと手の距離（前後移動）や画面解像度の変化に自動適応する動的プロポーションを実現。

2. 相互アンカー追従ライン (Line_Y) の計算
   - 人差し指指定時: 中指先（Landmark 12）のY座標をアンカー基準とし、指長差とオフセットを加味した Line_Y を算出。
   - 中指指定時: 人差し指先（Landmark 8）のY座標をアンカー基準とし、指長差とオフセットを加味した Line_Y を算出。
   - 指定指を振り下ろした際、アンカー指（もう一方の指）の位置にラインが踏みとどまるため、指定指が確実にラインを通過して打鍵判定が成立する構造。
   - 直下オフセット幅は現在 50% (L_hand * 0.50) に設定（画面上の [−] [＋] ボタンで 1%〜80% まで動的に微調整可能）。

3. 遅延極小化（ゼロレイテンシ同期）
   - requestVideoFrameCallback API を導入し、Webカメラ映像フレームの更新タイミングとトラッキング・描画ループを完全に同期。
   - 平滑化フィルターの位相遅れ（1〜2フレームのラグ）を排し、MediaPipeの最新フレーム座標を直接ライン計算と描画に直結。

4. 即時トリガー型打鍵ステートマシン (IDLE / HIT / RESET)
   - IDLE: 指先が判定ライン（Line_Y）より上空にある待機状態。
   - HIT: 指先が判定ラインを通過した瞬間（targetY >= lineY）に即座に打鍵を発火（待ち時間ゼロ）。
   - RESET: 打鍵後、指先が基準ラインより上空（Line_Y - L_hand * 0.10）に戻るまで再トリガーを防止。
   - チャタリング防止: 80ms のクールダウンにより同一指の小刻みな連続誤発音を防止。
   - 非指定指の完全マスク: 現在ターゲットとなっていない指の動きは打鍵判定を完全にスキップ。

5. 「メリーさんのひつじ」7音シーケンス演奏テスト環境
   - 右手打鍵テスト用シーケンスを定義:
       1音目: E4 (ミ) / 中指 (Landmark 12)
       2音目: D4 (レ) / 人差し指 (Landmark 8)
       3音目: C4 (ド) / 人差し指 (Landmark 8)
       4音目: D4 (レ) / 人差し指 (Landmark 8)
       5音目: E4 (ミ) / 中指 (Landmark 12)
       6音目: E4 (ミ) / 中指 (Landmark 12)
       7音目: E4 (ミ) / 中指 (Landmark 12)
       ※7音演奏後は先頭へ自動ループ
   - 指がラインを通過した瞬間に即座に発音し、同フレーム内でシーケンサーが次音符へ前進。
   - 追従ラインおよびターゲットリングが、即座に次の指定指（中指↔人差し指）へ移動して連続演奏が可能。

6. 白黒ミニマル演奏HUD & 描画フィードバック
   - 画面上部に演奏HUDを配置:
       * TARGET FINGER: 現在の指定指（中指 Middle / 人差し指 Index）
       * NOTE: 現在の音名（E4 ミ, D4 レ, C4 ド）
       * PROGRESS: 演奏進捗（1 / 7 〜 7 / 7）
       * STATE: 打鍵ステート（IDLE / HIT / RESET）
       * L_hand / Line_Y / 追従深さ (ΔY) / 直下オフセット微調整ボタン
   - Canvas上の視覚フィードバック:
       * ターゲット指: 白黒二重丸リング（打鍵成功瞬間に白フラッシュ）
       * アンカー指: 細いグレー丸＋十字マーカー
       * 判定ライン: 白細線（下地黒）、打鍵時は高輝度白フラッシュ、復帰待機時は破線
       * 打鍵波紋エフェクト: 白い同心円リングが拡散


■ 3. 主要ファイル構成と役割
--------------------------------------------------------------------------------
- src/anchorLineTracker.ts
    手の基準スケール L_hand 算出、右手指全5指（親指〜小指）の相互アンカー追従ライン計算、
    解剖学的長さ比率（fingerDiffRatio）の指別定義、およびライン通過即時トリガー型ステートマシン（IDLE/HIT/RESET）を担う独立モジュール。

- src/songSequencer.ts
    右手5指Cポジションを用いた「喜びの歌（歓喜の歌）」全15音シーケンス定義、および打鍵時の自動進行（advance）管理。

- src/main.ts
    Webカメラ起動、requestVideoFrameCallback 同期ループ、MediaPipe認識、
    打鍵検知時の Web Audio API 発音（PianoSynth連携）、全5指Canvas描画、UI更新の統合制御。

- index.html
    白黒ミニマルの演奏HUD（指名 THUMB〜PINKY、音名 C4〜G4、進捗 1/15、ステート、オフセット調整ボタン）およびカメラ画面。

- src/style.css
    白黒基調のデザインシステム（半透明黒背景、白文字、境界線、ステートバッジ等）。

- src/pianoSynth.ts
    Web Audio API によるリアルタイム・ピアノ倍音合成音源エンジン。

- src/handTracker.ts
    MediaPipe Tasks-Vision HandLandmarker ラッパー。片手検出時の左右フォールバック完備。

- src/virtualPositionManager.ts
    両手10本指ピアノ運指・ポジション自動管理モジュール（将来拡張用）。


■ 4. 現在の動作・検証状況
--------------------------------------------------------------------------------
- ビルド確認: `tsc --noEmit` および `npm run build` はエラーゼロ（コード0）で正常完了。
- 動作状態: Vite開発サーバー稼働中。
- 演奏挙動:
    Webカメラに右手をかざし、画面に表示される指定指（親指〜小指）を机面に向かって押し下げてラインを通過させると、
    即座に該当音（C4〜G4）が発音され、ラインとターゲットリング・アンカーマーカーが即座に次の指定指へ切り替わります。
    全15音をテンポよく打鍵して「喜びの歌」をループ演奏できる状態です。
