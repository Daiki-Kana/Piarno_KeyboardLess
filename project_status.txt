1. プロジェクト概要
--------------------------------------------------------------------------------
・名称: Piarno KeyboardLess（キーボードレス・ピアノ演奏Webアプリケーション）
・概要: 物理的な鍵盤やキーボードを使わず、机の上で指をタップ（打鍵）する動作を
        WebカメラとMediaPipeで骨格トラッキングし、机衝突の急減速加速度および
        共連れ誤爆抑止（Winner-Take-All 相対速度ガード）によって超低遅延・高精度に
        ピアノ演奏を行うブラウザアプリケーション。
・技術スタック:
  - 言語: TypeScript 5.7.3
  - ビルドツール: Vite 6.2.0
  - ビジョン認識: MediaPipe Tasks-Vision 0.10.18 (HandLandmarker)
  - フィルター: 3D One Euro Filter (ジッター抑制・急峻動作高速追従)
  - 音源: Web Audio API (オシレーター + ゲインエンベロープによるピアノ合成)
  - デザイン規約: 白黒・グレーを基調としたミニマルUI

--------------------------------------------------------------------------------
2. 各モジュールの役割と実装状況
--------------------------------------------------------------------------------

【1】ハンドトラッキング (`src/handTracker.ts`)
・MediaPipe Tasks-VisionのHandLandmarkerを使用し、両手10本の指先
  （親指:4, 人差指:8, 中指:12, 薬指:16, 小指:20）を含むランドマークを30fpsで追跡。
・GPU (WebGL) を標準とし、動作環境に応じたCPU自動フォールバックを実装。
・タイマー精度やフレーム間引きに対応したタイムスタンプ逆転防止を搭載。

【2】座標平滑化フィルター (`src/oneEuroFilter.ts`)
・指先座標（X, Y, Z）専用の「OneEuroFilter3D」を各指独立にインスタンス化。
・低速時の微小な手振れジッターを抑制しつつ、急激な指の振り下ろし（高周波入力）には
  遅延なくリニアに追従する動的カットオフ周波数制御を適用。

【3】机タップ（打鍵）検知エンジン (`src/tapDetector.ts`)
・垂直方向速度 ($v_y$: 下向き正) と急減速加速度 ($a_y$: 衝突時の負の急峻ピーク) を計算。
・二段階検知ロジック:
  1) 能動的振り下ろし（Active Down: $v_y \ge$ 閾値）の発生とピーク速度の記憶。
  2) 机衝突による急減速（Decel Peak / Sharp Velocity Drop）でインパクトを検知。
・親指(4)・小指(20)・薬指(16)に対する感度ブースト（可動域差の吸収）。
・チャタリング防止用の不応期（クールダウン: 130ms）。
・【Step 1: 相対速度比較（Winner-Take-All）ガード】
  - 他指の振り下ろしにつられて指定指がピクッと動いたことによる誤爆（共連れ発火）を防止。
  - 同フレームにおける同手他4指の最大下向き速度 $maxOtherVy$ を走査。
  - 条件: $targetFingerVy > maxOtherVy \times K$ を満たす場合のみ発音・進行を許可。
  - 係数 $K$: 初期値 1.4（動的変更対応）。
  - 他指静止時（$v_y \le 0$ や微小ノイズ $< 0.02$）は 0 として扱い、ゼロ除算や不当ブロックを完全回避。
・【Step 2: デバッグ支援・トリガー時ログ】
  - 打鍵候補発生時（衝突判定成立時）のみ、1行コンソールログを出力:
    `[TapGate] PASS: targetVy=..., maxOtherVy=..., ratio=..., K=...` または
    `[TapGate] BLOCKED: targetVy=..., maxOtherVy=..., ratio=..., K=...`
  - 毎フレームの無駄なログ垂れ流しを防止。
  - リアルタイム速度取得メソッド（`getLiveSpeedInfo`）および直近判定結果取得を提供。

【4】マイペース型楽曲シーケンサー (`src/songSequencer.ts`)
・自動時間進行ではなく、ユーザーが正しい打鍵を行うまで待機し、打鍵トリガーで1音ずつ進む方式。
・定義楽曲:
  1) 「メリーさんの羊 (右手単独テスト)」(全26音) ★現在デフォルト
     - ミ・レ・ド・レ・ミ・ミ・ミ / レ・レ・レ / ミ・ソ・ソ /
       ミ・レ・ド・レ・ミ・ミ・ミ・ミ / レ・レ・ミ・レ・ド
     - すべて右手（Right Hand）の基本5音（C4〜G4）に対応。
  2) 「きらきら星 (単音版)」
  3) 「きらきら星 (両手交互版)」

【5】仮想ポジションマネージャー (`src/virtualPositionManager.ts`)
・ピアノの運指に準拠し、音階（ピッチ）から打鍵すべき最適な指を動的決定。
・右手単独テスト用に、C4〜G4の5音を完全固定したマッピング定数 `RIGHT_HAND_FIXED_FINGERS` を提供:
  - 親指 (tipIndex: 4)  -> ド (C4)
  - 人差指 (tipIndex: 8)  -> レ (D4)
  - 中指 (tipIndex: 12) -> ミ (E4)
  - 薬指 (tipIndex: 16) -> ファ (F4) ※予備
  - 小指 (tipIndex: 20) -> ソ (G4)

【6】Web Audio API ピアノ音源 (`src/pianoSynth.ts`)
・ブラウザのオーディオコンテキストを用いた超低遅延ピアノ合成。
・単音再生（`playNote`）および和音再生（`playChord`）。
・打鍵速度（impactSpeed）に応じたベロシティ音量・減衰変化。

【7】統合制御・UI表示 (`src/main.ts`, `index.html`, `src/style.css`)
・Webカメラ映像 + 鏡像フルスクリーンCanvas描画。
・起動フロー: 「カメラを開始」-> 構え確認半透明プレビュー -> 「スタート」-> 3, 2, 1, START! カウントダウン -> 演奏突入。
・打鍵時の視覚フィードバック（白黒の波紋リングエフェクト + 指先フラッシュ）。
・画面配置（白黒ミニマルデザイン）:
  - 画面左上: 【演奏シーケンス進行パネル】
    - 曲名: MARY HAD A LITTLE LAMB
    - 進捗: `Note 1 / 26`
    - 現在指定指: `Target: Right Middle (E4)`
    - 次回予告指: `Next: Right Index (D4)`
  - 画面右上: 【TAP GATE デバッグパネル】
    - 係数 $K$ スライダー（範囲: 1.0 〜 2.5、刻み: 0.1、現在値表示）
    - 指定指名
    - 指定指の垂直速度 ($v_y$)
    - 他指の最大垂直速度 ($maxOtherVy$)
    - 相対比率 ($v_y / maxOtherVy$)
    - 直前判定結果 (`PASS: 打鍵発火` / `BLOCKED: 共連れ抑止` / `WAITING`)
・打鍵制御ルール:
  - 右手演奏テスト中、指定されたターゲット指で正しく打鍵（PASS）された場合のみ発音し、シーケンスを次の音符へ進める。
  - 指定外の指の打鍵、および共連れ判定でブロック（BLOCKED）された打鍵ではシーケンスを進めない。

3. 現在の到達度・実機動作検証状況
--------------------------------------------------------------------------------
・TypeScript型エラーゼロ、Vite本番ビルド（`npm run build`）完全通過。
・開発サーバー（`npm run dev`）が稼働中。
・実機Webカメラ環境において:
  - 机上に手を構えてスタート可能。
  - 右手で「メリーさんの羊」を順番に打鍵して1音ずつメロディを演奏可能。
  - 他指を激しく振り下ろした際につられた指のピクつきがBLOCKEDとして防がれる動作を、
    右上のデバッグ数値およびコンソールログでリアルタイムに観測可能。
  - スライダーで係数 $K$ を即座にチューニング可能。
